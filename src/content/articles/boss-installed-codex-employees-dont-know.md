有的公司，老板特别喜欢用 Codex，大手一挥，给全公司每个员工都装上，PRO账户也开好了。结果东西是发下去了，没几个人知道这玩意儿到底怎么用。

我猜这是绝大多数新人的真实处境。工具摆在面前，老板说"用起来"，可没人告诉你第一步该干嘛。

![](/images/boss-installed-codex-employees-dont-know/img-02.png)

如果你也是刚被装上 Codex、打开之后一脸懵的那个人，这篇就是写给你的。我尽量说人话，不讲技术，只讲一件事：  一个普通电商员工，怎么从零开始把
Codex 用起来。

#  1、 先说说，它和豆包到底差在哪

很多人第一次看到 Codex 会想，这不就是另一个聊天机器人吗？我用豆包、DeepSeek 也能写文案、改话术、做总结，干嘛非得用它。

![](/images/boss-installed-codex-employees-dont-know/img-03.png)

差别其实就一句话。

豆包、DeepSeek 更像一个聊天框，你把内容复制进去，它在框里回你。

Codex 更像一个坐在你电脑旁边的助手。它除了回答问题，还能在你允许的范围内看文件、整理资料、改文档、生成表格、拆任务、理流程。

所以聊天机器人适合"问一问"，Codex 适合"帮我做一段活儿"。

举个例子，写周报。用聊天机器人，你通常得自己复制一堆内容进去让它润色。用
Codex，你可以让它围绕一个项目文件夹，把会议纪要、数据表、工作记录直接整理成一版周报初稿。

老板让你用它，跟代码没关系。  他想要的，是你能把它当成一个干活的助手。
尤其电商公司，日常一大堆文案、表格、商品资料、竞品分析、客服话术、活动复盘，这些都能让 Codex 先帮你过一遍。

#  2、 在开始之前，先搞懂一个核心不同

打开 Codex，你会发现它长得和微信、和豆包差不多：左边一列对话，中间一个打字框，右下角一个发送按钮。打字、回车、它回你，这部分你早就会了，不用学。

但它有一个豆包没有的本事，这也正是公司让你用它的原因：

它能直接看你电脑里某个文件夹的资料，也能把整理好的结果写回那个文件夹。

豆包是个聊天框，你得把东西一段段复制进去。Codex
更像你给它指了一个抽屉，告诉它"资料都在这儿，你自己拿"。所以你会看到，界面最下面有一个文件夹的名字，这就是它当前正在看的那个抽屉。

#  3、 第一次用，记住三个地方就够

第一，先选一个文件夹（最下面那个文件夹按钮）。

![](/images/boss-installed-codex-employees-dont-know/img-04.png)

这一步最关键，也最容易被跳过。点一下底部的文件夹名字，选中你这次要处理的项目，比如「618直播复盘」。选好之后，这个文件夹里的资料它就能看了，生成的结果也会放回这里。

新手最常踩的坑，是上来就打字，忘了选文件夹，然后纳闷"我让它看的表格它怎么找不到"。  顺序记牢，先选文件夹，再说话。

第二，把资料给它（左下角的「+」号）。

![](/images/boss-installed-codex-employees-dont-know/img-05.png)

点「+」号，能把表格、文档、图片直接加进来。还有个更省事的办法，把文件全丢进上一步选的那个文件夹里，它自己就看得到。

还有一个方法是，比如你想让它读某个文件，你可以右键它，粘贴到聊天窗里，然后告诉你想做的事情（读数据、改数据、总结数据，或者基于这个数据写分析报告，做可视化，都行）

![](/images/boss-installed-codex-employees-dont-know/img-06.jpg)

第三，用人话说清楚你要干嘛（中间的打字框）。

打字框里把任务讲明白就行。具体怎么讲才清楚，下一节专门说。

![](/images/boss-installed-codex-employees-dont-know/img-07.png)

那个橙色的「完全访问」，要不要点

![](/images/boss-installed-codex-employees-dont-know/img-08.png)

界面上有个橙色的「完全访问」，不少人一看橙色就慌，以为是报错。它跟报错没关系。

它管的是一件事：Codex 在动你的文件、做操作之前，要不要先问你一声。

想稳一点，就让它每次动手前先问你，你看一眼确认了再放行，新手建议先这么用。

想快一点，就开「完全访问」，它做事就不再一步步问，自己干完。等你熟了、信得过它了再开也不迟。

记住一句话就够：橙色只是提醒你"它现在权限不小，留点神"。拿不准的时候，就选那档要它先问你的。

#  4、 模型选项，新手别管

界面上还有个「5.5 中」之类的选项，那是在选它"用多聪明的脑子干活"。新手阶段保持默认就行，别在这儿纠结，等你用顺手了、碰到难活儿再回来研究。

![](/images/boss-installed-codex-employees-dont-know/img-09.png)

喂资料之前，一句正经提醒

Codex 好用，但它终究是个工具，资料喂进去之前，先花一秒想想：

客户手机号、身份证、银行卡这类个人隐私，能去掉就去掉。

公司的真实成本、利润、还没公开的合同条款，喂之前先问清楚公司有没有规定。

实在拿不准的，问一句你主管，或者公司 IT。

说这些只是想让你养成个习惯。工具是公司发的，数据是公司的，多问一句不吃亏。

#  5、 Codex 适合帮你做什么

你可以先把 Codex 理解成一个"会处理资料的工作助手"。它比较适合做这些事。

整理资料，比如把一堆会议记录、商品资料、活动方案整理成结构清楚的文档。

分析表格，比如帮你看销售数据、直播数据、客服数据里有什么异常。

改写文案，比如把商品卖点改成详情页文案，把客服回复改得更自然。

生成初稿，比如周报、复盘、SOP、活动方案、直播脚本、短视频脚本。

检查遗漏，比如让它检查方案里有没有没考虑到的风险，文案里有没有表达不清楚的地方。

沉淀流程，比如把你平时反复做的工作整理成一份标准流程，下次直接复用。

它不擅长的事也得知道。别指望它一句话就帮你完成所有工作，别把最终判断完全交给它，更别它写什么你就直接发什么。它擅长的是帮你完成第一版、整理版、检查版，最后还得人来拍板。

#  6、 第一次使用 Codex，应该怎么提问

很多人第一次用 AI，最容易问这种问题：

> 「帮我写个活动方案。」
>
> 「帮我分析一下数据。」
>
> 「帮我写个文案。」

这些问题效果通常一般。你给的信息太少，它只能猜。

更好的方式，是把任务说清楚。你至少要告诉它四件事。

> 我要做什么。
>
> 我为什么要做。
>
> 我手上有什么资料。
>
> 我希望输出成什么样。

可以直接套这个模板：

> 「我现在要做【具体任务】，目标是【目标】。我手上有【资料或文件】。请你帮我输出【结果】，格式为【格式要求】。如果信息不够，请先问我。」

比如：

>
> 「我现在要做一场直播复盘，目标是找出本周转化率下降的原因。我手上有本周和上周的直播数据表。请你从流量、点击、停留、成交、商品结构几个角度分析，最后输出一版老板能看懂的复盘总结。如果信息不够，请先问我。」

这个提问，就比「帮我分析直播数据」好太多了。

Codex 不怕你话多，它怕你说不清楚。

#  7、 各岗位怎么用：先完整走一遍一个例子

我先带你把一个真实任务从头到尾走一遍，你能更直观地感受到 Codex 怎么配合你。我们就用上一节那个直播复盘。

第一步，选好这次复盘的文件夹，把本周和上周的直播数据表丢进去。

第二步，在打字框里把任务说清楚，也就是上一节那段提问。

第三步，它可能不会马上动笔，而是先反问你几个问题，比如"本周有没有换主播""有没有上新品""投放预算和上周比有没有变化"。把你知道的告诉它就行。

这一步很重要。它问得越细，结论越准，别嫌烦。

第四步，它给出第一版复盘。你大概率不会一次满意，没关系，直接追着改：

> 「结论太虚了，请针对每个下降的指标给出具体动作建议。」
>
> 「太长了，压到 300 字，老板没耐心看长的。」
>
> 「把核心结论提到最前面，后面再放分析过程。」

几轮下来，你就有了一版能直接交的复盘。整个过程你没写一个字的分析，你做的是指方向、给资料、提要求。这就是 Codex 和聊天框最不一样的用法。

举个实操例子，  我现在手里有这么一份数据表格  ，我需要统计25年和26年  常驻省份占比Top10，我直接把表格发给他，并跟他说：

> 这个是每个月的常驻省份 top10，帮我统计一下25和26年分别的常驻省份占比Top10 ，我目的是要看25年和26年各个维度的数据变化

#  9、 日常使用的几个小习惯

第一，一个项目开一个独立对话。比如「618 直播复盘」「夏季新品上新」「客服差评分析」分别开，别所有事情都塞进一个对话里。这样 Codex
更容易记住当前主题，你自己回头找也方便。

第二，一个对话只处理一个主题。运营方案聊到一半，别突然让它写客服话术。话题混在一起，后面结果容易乱。

第三，长任务要让它阶段性总结。聊久了之后，可以对它说：「请总结目前已经确认的信息、还没解决的问题、下一步要做什么。」这样后面继续做的时候不容易丢上下文。

第四，遇到 compact 不用紧张。你可以简单理解为，对话太长时，Codex
会把前面的内容压缩总结一下，好让任务继续进行。为了减少信息丢失，重要任务可以主动让它先整理一版「当前上下文总结」。

第五，文件按项目整理。别一次上传一堆无关资料。最好一个项目一个文件夹，里面分清楚活动方案、商品表、竞品资料、历史数据、会议记录。

第六，输出不满意时，别急着重开。直接追问修改就行。比如「太长了，压缩到 300
字」「语气太像广告，改得更自然」「不要段落，按表格输出」「结论太虚，请给具体建议」。

第七，重要任务先让它列计划。比如你可以说：「先别直接写，请先告诉我你准备怎么处理这个任务。」确认方向没问题，再让它继续做。

第八，每次结束前让它沉淀结果。比如「请把这次讨论整理成一份 SOP」「请把今天的结论整理成可复用模板」「请总结下次做同类任务时应该怎么提问」。

#  10、 新手 7 天练习

第 1 天，让 Codex 帮你改一封工作消息。重点体验它怎么调整语气。

第 2 天，让 Codex 帮你整理一份会议纪要。重点体验它怎么把散乱内容变成结构。

第 3 天，让 Codex 帮你写一版周报。重点体验它怎么从零散记录里提炼重点。

第 4 天，让 Codex 帮你分析一份表格。重点体验它怎么找异常和总结结论。

第 5 天，让 Codex 帮你优化一个商品卖点。重点体验它怎么把参数翻译成用户语言。

第 6 天，让 Codex 帮你做一份竞品对比。重点体验它怎么整理多份资料。

第 7 天，让 Codex 帮你把一个重复工作整理成 SOP。重点体验它怎么帮你沉淀流程。

不用第一天就学会所有功能。每天拿一个真实的小任务试一下，一周之后，你基本就知道它能帮你到什么程度了。

#  11、 关于 Skill，先知道有这回事就行

你以后可能会听到「Skill」这个词。可以先把它理解成公司提前帮你写好的「岗位说明书」，比如客服岗的回复规则、运营岗的复盘格式、设计岗的 brief
标准。配好之后，你不用每次都从头教 Codex 该怎么做，直接调用就行。

如果公司还没配，也完全不影响。先用这篇里的模板和岗位示例就够了。等公司配好了，到时候照着用即可。

#  12、 最后总结

Codex 不会把普通员工变成程序员，也帮不了你把所有活儿全干完。它更像一个能坐在你电脑旁边，帮你理资料、拆任务、出初稿、查遗漏的助手。

普通员工能不能用好它，关键就一个：你能不能把活儿说清楚。

你得告诉它，你要做什么，目标是什么，资料在哪，结果要什么格式，有哪些限制。

你说得越清楚，它越好用。你说得越模糊，它越爱瞎猜。

对电商公司来说，Codex 最适合先用在这几块：文案、表格、商品资料、客服话术、竞品分析、活动复盘、会议纪要、SOP。

别一上来就追求高级玩法。先从每天最烦、最重复、最需要整理的那一件小事开始。
