> 本章目标：把全课 **CE0–CE6** 拼成**一张能随身带走的办公桌解剖图** + **两页对照卡**。读完前面想巩固、或日后干活时想快速回忆"该用哪把刀、桌子是怎么坏的"，掏出这一张就够。
> 用法：正着用是**设计图**（往桌上摊什么、怎么摆），倒着用是**病理图**（桌子坏了往哪查）。盖住答案默写两张对照卡，是最好的自检。

## 2. 对照卡①（诊断用）：失败模式 ↔ 病因 ↔ 该用哪把刀 ↔ 一句话怎么修

> 桌子坏了时掏这张。症状告诉你病名，病名直接指向"哪把刀没用好"，那把刀就是你该抄起来修的刀（CE6 的核心心法）。

| 失败模式（中/英） | 一句话症状 | 病因（哪把刀没用好） | 该用哪把刀 | 一句话怎么修 |
|---|---|---|---|---|
| **❶腐烂**<br>context rot | "没明显错，就是**整体变迟钝**——越聊越蠢" | 只进不出：**裁剪(CE2)+压缩(CE3) 缺位**，信噪比垮 | 压缩 / 裁剪 / `clear` | 把桌面"瘦"回去：折叠陈账、裁掉杂物；最干脆 **`/clear`** 重开一张干净桌 |
| **❷中毒**<br>context poisoning | "早先**编错一个事实**，现在死咬着它往下推" | **裁剪(CE2)+校验 失守**：错的进了桌没被清掉 | 裁剪（删毒源）/ 校验 / `clear` | **定位毒源那张纸→物理删掉**（口头纠正无效！）；重则 `/clear` 后喂干净事实重启 |
| **❸分心**<br>context distraction | "让它找个小信息，它却**揪着旁边无关内容**绕进去" | **裁剪(CE2)+布局(CE1) 失守**：无关的太多且摆错位 | 裁剪 / 布局 | 裁掉那坨无关内容；把"现在最要紧的任务"**顶回结尾高权重位**（re-ground） |
| **❹矛盾**<br>context clash | "一会儿按 A、一会儿按 B，**自己跟自己打架**" | **压缩(CE3)+记忆一致性(CE5) 失守**：作废旧账没清 | 压缩（清旧账）/ 修记忆 | **删掉作废那条、留当前权威那条**（每件事只剩一个声音）；跨会话冲突去更新外部记忆 |

> 鉴别诊断口诀（CE6）：**先分"整体钝 vs 具体歪"**——整体泛泛变迟钝、无单点错 → ❶腐烂；歪到某个具体东西上，再问根子：死咬错事实 → ❷中毒，被无关勾走 → ❸分心，两条冲突间摇摆 → ❹矛盾。
> 通用兜底：拿不准或病太重 → **`/clear` 重开干净桌**，永远是最快、最便宜的复位键。

## 3. 对照卡②（技术速查）：杠杆/刀 ↔ 一句话作用 ↔ 代价 ↔ 适用场景

> 设计桌子时掏这张。覆盖 CE1 位置布局 + 四把刀（裁剪 / 压缩 / 检索 / 外部记忆），无遗漏。

| 杠杆 / 刀（章） | 一句话作用 | 代价 / 暗坑 | 适用场景 |
|---|---|---|---|
| **杠杆① 位置布局**<br>(CE1) | 位置即权重：铁律钉开头、急活贴结尾、杂物压中段、开头焊死复用缓存 | **最廉价**——不删 token、不换模型，只换座位；但盲区不是保险箱，关键的塞中段=没放 | 任何时候都先排座位；长期规则进 system，刚检索回的事实贴结尾 |
| **刀一 裁剪 / 筛选**<br>(CE2) | 进桌前的门禁：每个 token 都要挣得它的位置，只放相关的 | 门口拦一次只付一道过滤成本；放进来再清要交 token+延迟+注意力三道税（且 token 税按轮累计） | 工具吐 500 行只留报错 3 行；搜出 50 条只放最相关 5 条；任务切换丢旧往返 |
| **刀二 压缩 / 总结**<br>(CE3) | 把桌上一长摞陈账，折成一张占地极小的便笺 | **有损交易**——拿细节换空间；暗坑是"摘要套摘要"**信息无声漂移**（复印件的复印件） | "大意要留、细节可弃"的长对话历史；压中段陈账、留结尾命脉；硬通货钉死在滚动之外 |
| **刀三 检索注入 RAG**<br>(CE4) | 海量知识放窗外书架，用到哪页才捞哪页上桌 | **垃圾进垃圾出**——七分功夫在检索，捞错页比瞎猜更危险；建库/维护有成本 | 大体量、半结构化、靠语义找的静态知识库；**别用于**小知识(直接上桌)、精确数据(用工具查) |
| **刀四 外部记忆 / 卸载**<br>(CE5) | 不必时刻在眼前的信息写进文件，桌上只留指针，要用再 Read 回 | 细节**完整保留可复原**（这是它和压缩的分界）；纪律是"用到才读"，预加载=白卸载 | "细节不能丢、又不必时刻在眼前"的自产状态；任务内草稿纸(短期)、偏好/项目约定(跨会话长期) |

> 选刀决策树（CE4+CE5 合并）：**小知识** → 直接整段上桌（裁剪够用）；**海量静态共享知识** → RAG（刀三）；**agent 自产的动态状态/往事** → 外部记忆（刀四）；**已在桌上、太长的对话历史** → 压缩（刀二）；**精确结构化数据** → 用工具查（别上 RAG）。四把刀各司其职，不抢活。

## 4. 核心矛盾 + 三连问口诀（回收）

整门课的难度，浓缩成一道夹在两端之间的**取舍题**（CE0 立的地基）：

| | 信息**太少**（桌子太空） | 信息**太多**（桌子太满） |
|---|---|---|
| 后果 | 瞎猜、**幻觉** | **溢出** / 变慢变贵 / **中间遗忘**（最阴险：不报错、悄悄漏看） |
| 失败模式 | A：窗口太空 | B：窗口太满 →（细分）腐烂 / 中毒 / 分心 / 矛盾 |

> **上下文工程的全部手艺，就是在这两端之间走钢丝：把"正好够用"的信息，放在"模型最容易看到"的位置。**

落到每一轮的动作，就是那句**三连问口诀**——对桌上每一块信息，连问三遍：

> **① 它现在用得上吗？**（用不上 → 裁剪，CE2）
> **② 它能更短吗？**（太长但有用 → 压缩，CE3）
> **③ 它能先收起来、要用再取吗？**（细节要留但不必在眼前 → 检索 / 外部记忆，CE4/CE5）

三问过完还留在桌上的，再用 CE1 给它**排座位**（铁律钉开头、急活贴结尾、杂物压中段）。

## 5. 与姊妹课的关系：本课是 Harness L4 的放大镜

本课不是凭空起的——它是姊妹课 **Harness Engineering** 里 **L4「上下文工程」**那一章的**放大**：L4 把"办公桌 + 四把刀"作为入门讲义**介绍**给你，本课把每一把刀从"听说过"磨成"用得动"的手术刀，再补上 L4 欠你的"位置布局"和"失败诊断"两把。

## 6. "随身地图"使用说明：两张对照卡正反着用

这门课压成两张卡（第 2、3 节），它们是同一套刀法的两个方向：

1. **正着用 = 设计（从卡②出发）**：开一个新任务前，过一遍"选刀决策树"——这堆信息该裁、该压、该检索、还是该卸载？留下的怎么排座位（CE1）？这是**把信息往桌上摊之前**的设计动作。
2. **倒着用 = 诊断（从卡①出发）**：agent 已经"长歪"了，用鉴别诊断口诀先认病名（钝 vs 歪；毒/吵/打架），病名顺着卡①指向"哪把刀没用好"，那把刀就是解药。这是**桌子已经坏了之后**的修复动作。
3. **自检方法**：盖住卡①的后三列，只看"症状"，默写"病因 + 该用哪把刀 + 怎么修"；再盖住卡②的后两列，只看"杠杆/刀"，默写"作用 + 代价 + 场景"。两张都能默出来，这门课就吃透了。
4. **挂回真实场景**：拿一个你真用过 Claude Code 的会话，逐项问自己——它哪轮在 `Compacting`（压缩）？哪步先 `Grep` 再 `Read`（检索/裁剪）？`CLAUDE.md` 是不是钉在开头（位置布局 + 跨会话记忆）？用久了变笨是得了哪种病？把抽象的刀挂回你亲眼见过的动作。

## 一句话带走

> **整个 Context Engineering 就一张图：上下文窗口是一张有分区、分区带权重的办公桌（开头/结尾是焦点、中段是盲区）。五个杠杆经营它——位置布局排座位，四把刀（裁剪挡门、压缩折叠、检索按需捞、外部记忆卸载）管"往桌上摊什么"；对每块信息连问"用得上吗 / 能更短吗 / 能先收起来吗"，在"太空"与"太满"之间走钢丝。倒过来，这五把刀就是听诊器：桌子坏了的四种病（腐烂、中毒、分心、矛盾）各对应某把刀没用好，而 `/clear` 重开一张干净桌是最便宜的复位键。把这张办公桌解剖图和那两页对照卡记住，你就拥有了设计、诊断、改进任何 agent 桌面的随身工具——因为 agent 的智力瓶颈，从来不在模型脑力，而在这张桌子被管得多好。**
