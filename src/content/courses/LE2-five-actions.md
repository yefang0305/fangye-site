# LE2 · 一个循环的五个动作

> 本层目标：解剖一个自动循环转一圈时发生的五个动作，搞懂如何用一个真实例子把它们串联起来。

---

## 0. 先讲一个画面

一听到“循环”，你的脑子里可能浮现的是一段无限打转、空转的代码。
但在 Loop Engineering 里的循环不是空转的，它每转一圈，都在干一件具体的活。

我们将以 Addy Osmani（Google Chrome 团队工程师）在日常开发中使用的那个被反复引用的 **triage loop（自动分诊循环）** 为例：
每天早上，一个自动化调度器自动跑起来，去读昨天的测试报错、开着的 issue，把分诊结果写入一个 `TODO.md` 状态文件。它为每个值得修的 Bug 开一个隔离的 Git 分支，派一个小弟 Agent 改代码，派第二个小弟 Agent 跑单元测试审查，过了就自动开 PR，搞不定的丢进收件箱留给人。

这个 loop 的精妙之处就在于：**它没有一步需要人去点，但该停的时候能老老实实停下来等人。**

我们将这转一圈发生的动作，拆成五个确定性的基本动作：**发现、交付、验证、持久化、调度。**

---

## 1. 五个动作详解：逐个看

### 动作一：发现（Discovery）
* **要做什么**：搞清楚“这一圈该干什么”。
* **关键点**：必须是 **Agent 自己去找活**，而不是你每天早上把 Bug 喂给它。在 Addy 的例子里，它是用一段 triage 脚本去读 CI 失败日志和 issue tracker。
* **设计细节**：触发的不应当是一大段写死的 Prompt，而是一个固化的 **Skill（技能文件，如 SKILL.md）**。发现逻辑变了，改 Skill 就行，而不是去改定时器配置。

### 动作二：交付（Handoff）
* **要做什么**：把任务从“调度中心”分发给“干活的子 Agent”。
* **关键点**：**必须开辟隔离的 Worktree（Git 工作区）**。如果多个 Agent 在同一个工作目录下改代码，文件冲突就是迟早的事。交付的时候就把它们物理隔开，一个人在一间小黑屋里改。

### 动作三：验证（Verification）
* **要做什么**：检验这一版写得对不对。
* **关键点**：**Maker/Checker 角色分离**。写代码的那个 Agent（Maker）绝对不能当裁判。让它自己检查作业，它倾向于自信地拍胸脯说没问题。必须换一个带着严格审查指令的独立 Agent（Checker）对照项目规范去挑刺，甚至换一个更严格的底层模型。
* **名言**：一个 Loop 难的不是转起来，难的是在里面塞一个“能说不”的东西。

### 动作四：持久化（Persistence）
* **要做什么**：把验证通过的结果，写到当前对话窗口之外的地方。
* **关键点**：AI 会忘，但仓库不会（The agent forgets, the repo doesn't）。通过连接器自动开 PR，或者写进磁盘上的 markdown 状态文件里。没有这一步，AI 下一次醒来就会彻底失忆，永远在原地打转。

### 动作五：调度（Scheduling）
* **要做什么**：决定下一圈什么时候转，怎么转。
* **关键点**：把“我手动去跑了一次”真正变成“它自动在转”。通常挂在 Cron 定时器或者 GitHub Actions 触发器上，完成“发现 ➔ 交付 ➔ 验证 ➔ 续写状态文件”的闭环。

---

## 2. 五个动作速查表

把这五个动作连在一起，循环的骨架就清晰了：

| 动作 | 在 triage loop 里干什么 | 核心目标 |
|---|---|---|
| **发现 (Discovery)** | Skill 脚本读取 issue 和 CI 失败 | 自己找出这圈该干的事 |
| **交付 (Handoff)** | 每一个发现开一个 Git worktree | 将任务隔离着分发出去 |
| **验证 (Verification)** | 换第二个 Agent 对照测试严格审查 | 引入一个能说“不行”的哨兵 |
| **持久化 (Persistence)** | 自动开 PR，更新状态文件记下进度 | 把记忆落盘，跨运行不失忆 |
| **调度 (Scheduling)** | 每早自动化触发运行 | 让它自己一圈一圈转下去 |

---

## 3. 小练习 / 思考题

1. 在开发中，如果我们省略了“交付”中的 worktree 隔离，可能会发生什么冲突？
2. 为什么说“一个你信得过的验证者（Checker），是你敢走开的唯一理由”？
3. 如果今天的一圈没跑完，状态文件（持久化）是如何在明早帮助它“续命”的？

---

## 一句话带走

> **一个循环转一圈由发现、交付、验证、持久化和调度五个动作组成。发现是逻辑上限，验证是安全下限，而持久化状态文件是跨会话的记忆脊柱，它们通过定时调度串联成一个无人值守的闭环。**
