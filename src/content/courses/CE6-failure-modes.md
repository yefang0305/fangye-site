# CE6 · 上下文失败模式与诊断

> 本章目标：这是全课的**压轴诊断章**。前五章你磨了五把工具（位置布局 + 四把刀），都在教你"怎么把桌面收拾好"。本章反过来——当桌面**已经坏了**、agent 突然变笨/胡说/自相矛盾，你怎么**反推是哪个环节出的问题、该抄起哪把刀去修**。把前面所有刀法合起来，第一次不是当工匠用，而是**当医生用**。
> 拧的旋钮：暂无——本章不教新动作，教**诊断学**：把磨好的五把刀倒过来当听诊器。

---

## 0. 先讲一个画面

你跟你的 agent 聊得正顺。前二十分钟，它思路清晰、一击即中，你心想这玩意儿真聪明。

然后，**不知从哪一刻起，它开始"长歪"了**——而且是四种不同的歪法，你多半都撞见过：

- **越聊越蠢。** 没有任何一个明显的错误，它就是整体变迟钝了：回答开始啰嗦、抓不住重点、把你十分钟前说过的话当没说过。你没改模型、没改问题，它却像换了个更困的脑子。
- **开始一本正经地胡说。** 它早些时候顺嘴编了一个不存在的函数名 / 一条记错的事实，你没纠正。结果**接下来它把这个错的当成真的，反复引用、越说越笃定**，整段推理都建在那块沙地上。
- **被带跑题。** 你贴了一大段日志、一篇长文档进去找一个小信息，结果它揪着里面某个无关的细节不放，绕进去出不来了——**它的目光被那堆杂物勾走了**。
- **自己跟自己打架。** 你前面说"用方案 A"，后面又补了句"其实 B 也行"，它就开始**摇摆**：一会儿按 A 写、一会儿按 B 写，甚至同一段里前后矛盾，因为它桌上同时摊着两张互相打架的纸。

这四种"长歪"，脑子都没变——**变的还是桌面**（回收 CE0 的总主张）。但和"窗口太空/太满"那种粗粒度诊断不同，它们是四种**有名有姓、成因各异、各有解药**的病。

会修桌子的人很多；**能一眼看出桌子是怎么坏的**，才是医生。这一章就是发你一本病理手册。

## 1. 核心概念：上下文的四大失败模式

先把 CE0 立的那张大网回收一下。CE0 给过你**两大失败模式**，那是粗诊断：

- **失败模式 A：窗口太空**——该给的没给够，模型瞎猜、幻觉。
- **失败模式 B：窗口太满**——塞太多太杂，溢出 / 变慢 / 中间遗忘。

本章做的是**细诊断**：把"太满/太杂"这一端，进一步解剖成四种**有独立病名**的病理。它们都属于"桌面坏了"，但坏法不同、查法不同、解药不同。这是市面上最少被讲清的一张表——记住它，你就有了一套病理学词汇：

| 失败模式（中/英） | 大白话 | 办公桌类比 | 一句话症状 |
|---|---|---|---|
| **上下文腐烂**<br>context rot | 桌上堆得又满又杂之后，整体表现**缓慢、全面地下滑**——不是某条信息错，是"信噪比"垮了 | 桌面被几百张纸埋住，你每找一样东西都得扒半天，越扒越慢、越扒越乱 | "它没**明显**错，就是**整体变迟钝**了——越聊越蠢。" |
| **上下文中毒**<br>context poisoning | 一条**错误/幻觉**信息被写进了上下文，之后被**反复引用、自我强化**，越错越笃定 | 桌上混进一张写错的便条，它被你当成事实抄了一遍又一遍，谎言滚成了"档案" | "它早先编错了一个事实，现在**死咬着这个错的往下推**。" |
| **上下文分心**<br>context distraction | **无关信息**把模型的注意力勾走，它揪着不相关的细节打转，偏离正事 | 桌角一张花花绿绿的传单，比正中央那份正经文件还抢眼，你的目光老往那飘 | "我只想让它找一个小信息，它却**揪着旁边的无关内容**绕进去了。" |
| **上下文自相矛盾**<br>context clash | 上下文里**同时存在互相冲突**的信息，模型在两者间**摇摆**、前后不一致 | 桌上摊着两张互相打架的纸（一张说 A、一张说 B），你照哪张做都觉得不对，于是来回横跳 | "它一会儿按 A、一会儿按 B，**自己跟自己打架**。" |

术语注释（首次出现，就地中英 + 类比）：

- **上下文腐烂（context rot）**：随上下文堆得越满越杂，模型整体表现**渐进式、无声地**下降的现象。注意它的特征是"**没有单点错误，只有整体退化**"——这正是它最难抓的地方。L4 只来得及给它点个名，本章把它当病来拆。它和 CE0/CE1 讲的**中间遗忘（lost in the middle）**是亲戚：腐烂是"全桌信噪比垮掉"的总现象，中间遗忘是它最典型的一个症状（关键纸沉进了中段盲区）。
- **上下文中毒（context poisoning）**：错误或幻觉信息一旦进入上下文，就会被后续推理**当成已确立的事实反复引用**，形成"错→引用错→更信这个错"的**自我强化回路**。类比：一句谎言被写进了卷宗，后面每个人都照卷宗办事，谎言就有了"权威"。
- **上下文分心（context distraction）**：上下文里的**无关但显眼**的内容，抢占了模型本该投给正事的注意力。类比：你想专心看书，桌角却放着一部一直在亮的手机。
- **上下文自相矛盾（context clash）**：上下文中**并存两条及以上互相冲突**的信息（旧指令 vs 新指令、文档 A vs 文档 B、用户改过的需求 vs 改之前的需求），模型缺乏裁决依据，于是在它们之间**反复横跳**。类比：两个领导给你下了相反的命令，你哪个都不敢得罪，动作就变形了。

> 一句话记住四者的区别：**腐烂是"太杂"（整体退化）、中毒是"有毒"（错的被供起来）、分心是"太吵"（被无关的勾走）、矛盾是"打架"（两张纸互掐）。**

## 2. 原理"为什么"：每种病的成因，对应"哪把刀没用好"

这一章最值钱的心法在这里：**四大失败模式，本质都是前五章某把刀"没用好"留下的病灶。** 所以——

> **前五章正着用是"怎么收拾桌面"，倒过来就是"桌面坏了该往哪查"。刀法即诊断依据。**

逐个拆，每种病都回答两件事：**它从哪来**、**是哪把刀没用好**。

### 2.1 上下文腐烂 ← 压缩 / 裁剪没用好

**成因**：上下文只进不出。每轮对话、每次工具返回都往桌上拍新纸，却没人定期清桌。堆到一定程度，信号被噪声稀释——模型每次"扫一遍桌面"都要趟过越来越多的无关内容，关键信息沉进中段盲区（中间遗忘），整体表现就**无声地、渐进地**滑坡。它不报错，所以最隐蔽。

**哪把刀没用好**：
- **裁剪（CE2）失守**——垃圾在门口没拦住，全放进来等扫地了。
- **压缩（CE3）缺位**——长历史该折叠成摘要时没折，旧账越堆越厚。

> 腐烂 = 该裁的没裁 + 该压的没压。解药：抄起裁剪和压缩，把桌面"瘦"回去；最干脆的是 `/clear` 重开一张干净桌（手动行使裁剪到极致）。

### 2.2 上下文中毒 ← 裁剪 / 校验没用好

**成因**：一条错信息（模型自己的幻觉、或一份本就有误的资料）进了上下文，且**没被及时清除或标记为"存疑"**。由于模型默认信任自己桌上的东西，这条错就被当成事实带进后续每一步，还会被复述、被引用——**每复述一次，它在上下文里的"存在感"就强一分**，于是越错越笃定。这是四种病里**最危险**的，因为它会污染整条推理链。

**哪把刀没用好**：
- **裁剪（CE2）失守**——错的内容没在进桌时被筛掉，或产生后没被及时清出去。
- **缺了一道"校验"门**——CE2 的门禁本该不仅拦"无关"，还要对"可疑事实"留个心眼；中毒说明这道校验没设。

> 中毒 = 错的进了桌、还没被清出去。解药：**定位毒源那张纸 → 物理删掉它**（不是嘴上纠正——只要它还躺在上下文里，就还会被引用），重则 `/clear` 后用"干净的事实"重启。记住：对中毒，**口头纠正往往无效，删除才有效**。

### 2.3 上下文分心 ← 裁剪 / 布局没用好

**成因**：上下文里塞进了**无关但显眼**的内容（一整篇长文档、一大坨日志、上一个任务的残留），它们体量大、或位置抢眼，把模型的注意力从正事上勾走。和腐烂的区别是：腐烂是"整体变钝"，分心是"**被某块具体的无关内容带偏到岔路**"——目标明确地跑歪了，而不是泛泛地变迟钝。

**哪把刀没用好**：
- **裁剪（CE2）失守**——那坨无关内容压根不该整个进来（500 行日志只该留报错那 3 行）。
- **布局（CE1）失守**——就算要放，也不该放在结尾那种高权重位把正事挤下去；该把当前任务顶到最显眼处，把杂物压进中段。

> 分心 = 无关的太多 + 还摆错了位置。解药：裁掉那坨无关内容（CE2），并把"现在最要紧的任务"重新顶回结尾高权重位（CE1，相当于给它 re-ground）。

### 2.4 上下文自相矛盾 ← 压缩 / 记忆一致性没用好

**成因**：上下文里**并存了两条打架的信息**。最常见三种来源：① 你中途改了需求，但**旧需求还躺在上面没删**（旧 vs 新）；② 两份资料/两条记忆本身就冲突（文档 A vs 文档 B）；③ 压缩时摘要写得含糊，和后来的原文对不上（摘要 vs 现实）。模型没有裁决"该信哪条"的依据，于是在两者间摇摆。

**哪把刀没用好**：
- **压缩（CE3）没用好**——压缩时没把"已被推翻的旧决定"清掉，让作废的旧账和新账一起留在了桌上。
- **记忆一致性失守（CE5）**——外部记忆/跨会话存下的旧偏好、旧结论，和这一轮的新事实冲突了，却没人去对账、去更新。

> 矛盾 = 两张打架的纸同时在桌上。解药：**找出冲突的两条，删掉作废的那条、留下当前权威的那条**（让上下文里对每件事只有"一个声音"）；跨会话的冲突则去更新外部记忆，别让陈年旧结论压着新事实。

### 把全章心法压成一张对照表

| 失败模式 | 一句话成因 | 哪把刀没用好（诊断依据） | 主修工具 |
|---|---|---|---|
| 腐烂 rot | 只进不出，桌面又满又杂、信噪比垮 | 裁剪 + 压缩 缺位 | 压缩 / 裁剪 / `clear` |
| 中毒 poisoning | 错信息进了桌、被反复引用自我强化 | 裁剪 + 校验 失守 | 裁剪（删毒源）/ 校验 / `clear` |
| 分心 distraction | 无关显眼内容把注意力勾走 | 裁剪 + 布局 失守 | 裁剪 / 布局（顶回正事） |
| 矛盾 clash | 两条打架的信息并存，模型摇摆 | 压缩 + 记忆一致性 失守 | 压缩（清旧账）/ 修记忆 |

> 读这张表的正确姿势：**症状告诉你"病名"，病名直接指向"哪把刀没用好"，那把刀就是你该抄起来修的刀。** 这就是把前五章倒过来当听诊器。

## 3. 诊断流程：症状 → 怀疑哪种病 → 查哪里 → 用哪把刀修

光有病名还不够，你需要一条**站在症状面前能立刻跑起来**的流程。四步：

1. **看症状**：它到底是怎么个"长歪"法？（迟钝？咬着错的？跑岔路？前后矛盾？）
2. **怀疑病名**：用第 1 节那张"一句话症状"表对号入座。
3. **查哪里**：去上下文里找证据——是堆太满了？混进了哪张错便条？哪坨无关内容在抢戏？哪两张纸在打架？
4. **抄哪把刀**：用第 2 节的对照表，对症下刀。

关键是第 1→2 步的**鉴别诊断**——四种病的症状容易混，靠两个问题就能劈开：

- **问题一：是"整体钝"还是"具体歪"？**
  - 整体泛泛变迟钝、没有单点错 → 偏 **腐烂**。
  - 有明确的"歪到某个具体东西上" → 往下问问题二。
- **问题二：那个"具体的歪"，根子是什么？**
  - 死咬着一个**错的事实** → **中毒**。
  - 被一坨**无关内容**勾走 → **分心**。
  - 在**两条冲突信息**间摇摆 → **矛盾**。

## 4. Claude Code 锚点：四种"长歪"的体感诊断

Claude Code 就是一台你天天在用的 agent，这四种病你其实**都体感过**，只是没给它们起过名字。这张表把"用着用着不对劲的体感"翻译成"病名 + 该做的动作"——尤其是**什么时候该开新会话 / `clear`**：

| 你在 Claude Code 的体感 | 这是哪种病 | 该做什么（动作） |
|---|---|---|
| 同一会话用了很久，它**越来越啰嗦、抓不住重点、忘了你早先说的话** | 腐烂 rot | **开新会话 / `/clear`**——别在堆满旧账的桌上硬撑；或让它先总结再继续（压缩） |
| 它早先**记错 / 编了一个事实**（错的文件名、不存在的 API），后面**死咬着这个错往下写** | 中毒 poisoning | 光打字纠正常常没用——**`/clear` 重开**，开头就把正确事实喂清楚；或明确叫它"忘掉刚才那条，X 才是对的" |
| 你贴了**一大段日志 / 长文档**让它找个小东西，它却**揪着里面无关的部分**绕进去 | 分心 distraction | 别整坨贴——**只贴相关那几行**（手动裁剪）；或把"我到底要什么"重申一遍顶到最后（re-ground） |
| 你**中途改过需求**，它却一会儿按旧的、一会儿按新的，**前后打架** | 矛盾 clash | **明确宣告废止旧需求**："忽略之前说的 A，现在一律按 B"；改动大就 `/clear` 带着最终需求重开 |
| 任务切换时你顺手 `/clear` | 预防，而非治疗 | 这是**最便宜的护理**——换任务就换张干净桌，从源头掐掉腐烂/分心/串味 |

> 一句实操心法：**`/clear` 不是"我搞砸了"的认输键，而是上下文工程里最高频、最划算的保健动作。** 老手开新会话的频率，远高于新手——因为他们知道"在脏桌上硬撑"的隐性成本（变慢、变贵、变蠢、串味）比"重新交代一遍背景"贵得多。换任务就换桌，是肌肉记忆。

## 小练习 / 思考题

1. 四大失败模式各用一句"症状"区分开：分别对应"越聊越蠢 / 死咬错的 / 被无关内容带偏 / 自己跟自己打架"的是哪个？
2. 为什么说**中毒**是四种病里最危险的？它和单纯"答错了一次"有什么本质区别？
3. 你发现 agent 死咬着一个它早先编错的函数名不放。你**口头纠正了它，它却没改过来**——为什么口头纠正常常无效？正确的修法是什么？
4. **腐烂**和**分心**症状有点像（都让回答变差），用诊断决策树的第一个问题把它俩劈开：你该问什么？两者的答案分别是什么？
5. 把第 2 节的心法默写出来：四大失败模式分别对应"哪把刀没用好"？（腐烂 / 中毒 / 分心 / 矛盾）
6. 为什么说 `/clear` 既是"治疗"又是"预防"？举一个"治疗"场景和一个"预防"场景。

<details>
<summary>参考答案</summary>

1. 越聊越蠢 = **腐烂**；死咬错的 = **中毒**；被无关内容带偏 = **分心**；自己跟自己打架 = **矛盾**。
2. 因为中毒会**自我强化、污染整条推理链**：错的信息一旦进上下文且没被清除，就会被反复引用，每复述一次"存在感"就强一分，越错越笃定。而单纯"答错一次"是孤立事件，不会持续传染后续每一步。本质区别：一次性错误 vs 留在上下文里持续传染的"毒源"。
3. 因为只要那条错信息**还物理躺在上下文里**，模型就还会看到它、引用它——你的口头纠正只是又往桌上加了一张"纸"，没把那张错的拿走，两张纸还会打架（甚至退化成矛盾）。正确修法：**定位并删除毒源那段内容**（或 `/clear` 重开，开头喂正确事实）。对中毒，删除才有效，纠正往往无效。
4. 该问决策树第一题：**"是整体泛泛变迟钝（无单点错），还是歪到了某个具体的东西上？"** 腐烂的答案是"整体钝、没有单点错"；分心的答案是"歪到了某坨具体的无关内容上"——目标明确地跑岔了，而非泛泛变钝。
5. **腐烂** ← 裁剪 + 压缩 缺位（只进不出）；**中毒** ← 裁剪 + 校验 失守（错的进了桌没清掉）；**分心** ← 裁剪 + 布局 失守（无关的太多且摆错位）；**矛盾** ← 压缩 + 记忆一致性 失守（作废旧账没清、跨会话记忆没对账）。
6. **治疗**：会话用久了它变蠢/串味/咬着错的不放，`/clear` 重开一张干净桌，立刻复位（治已经发生的腐烂、中毒）。**预防**：每次切换到不相关的新任务时顺手 `/clear`，从源头掐掉旧任务残留造成的腐烂/分心/串味——病还没发生就拆掉了温床。

</details>

## 一句话带走

> **这是当医生的一章：agent"长歪"不是脑子变了，是桌面坏了，而坏法有四种有名有姓的病——腐烂（太杂，整体退化）、中毒（有毒，错的被供起来反复引用）、分心（太吵，被无关内容勾走）、矛盾（打架，两张纸互掐）。诊断只需两问：先分"整体钝 vs 具体歪"，再给"歪"分"毒/吵/打架"。最妙的是——每种病都精确对应前五章某把刀"没用好"（腐烂↔压缩+裁剪、中毒↔裁剪+校验、分心↔裁剪+布局、矛盾↔压缩+记忆一致性），所以把前五章倒过来，就是你的听诊器。而 `/clear` 重开一张干净桌，是这门手艺里最便宜、最可靠的复位键——会用它的频率，是新手和老手的分水岭。**
